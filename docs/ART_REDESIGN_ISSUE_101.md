# Issue #101 — Q 萌 3D 太空玩具舰队：实施记录和审美验收

**任务来源：** 用户否决 #100，先由 PR #102 完整恢复 #99 后的源树，再从干净 \`dev\` 开始重做。对比参考为 ReactMono 的真实 3D「晴湾小镇」：大形与色块先行、有限塑料材质、暖主光、冷补光、角色独立表演。不是复制棋盘俯视与 UI。

## 本次真的改动了什么
- **不是 #100 的几何小幅调整。** \`src/render/ShipModels.ts\` 重新雕刻玩家、Scout、Raider、Guardian 四类实时 Three.js 整体网格：胶囊主壳、圆厚短翼、宽座舱、大独眼、独立双炮、厚盾能量核；所有对象在四型号中使用同一套大比例、克制配色和柔和高光语言。所有零件的网格源码仍可编辑。
- \`src/render/P3Palette.ts\` 主光偏暖、天光偏薄荷、边缘偏蓝青，保持 4 光源和原性能边界。
- \`src/render/RingedPlanet.ts\` 原三维旋转带环行星改为淡彩层次，不叠加伪 2D 球体。
- \`public/art/backgrounds/toy-orbit.svg\` 纯原创可编辑柔雾星空，**实时加载的同源素材**，无外链，无摄影写实纹理。来源是本次编码制作的 SVG 参数化矢量；1600×900；中心暗静，四角的暖冷云气给人物留表演空间。旧 P4 星空仍保存在仓库，通过 \`?galaxy=veil\` 可单独调出用于诚实对比，勿再用同一张图充当前后两版。
- 播放中玩家翼内衬依权威姿态和后坐力轻微弹性活动；没有改变二维规则、速度、弹道、碰撞或射击原点。
- \`tests/toy-art.browser.spec.ts\` 必须取 WebGL 真实游戏与 3D 模型近景，三种视口；\`tests/models.test.ts\` 验证命名结构、实际体积排序及碰撞尺寸安全。
