# P3/D3 Q 版极简游戏 HUD

- 实现源码：`src/App.tsx` + `src/style.css`。生命图标是仓库内可编辑的原始 SVG 路径内联渲染，不是外链贴图；保持屏幕阅读器可读的“生命”和数量。
- 视觉层次：左上作品名/关卡选择、顶部中央分数/波次/生命、右上小按钮；主战场依旧全视口。统一紧凑中文排版、浅灰蓝文字与小面积浅青重点色。
- 只在准备状态出现键盘操作提示，开战后无技术文案和工程面板；调试面板仅用户手动打开。排行榜和音频都是手动唤出的可收起 DOM 控件，保持焦点、原生输入与音量持久化。
- 触屏按钮采用最小 54～64px 圆角半透明触控面，横竖屏与安全区避让，`pointer-events` 保留多点按压；对局暂停时禁用。没有增加顶栏容器高度或缩小 canvas。
- 截屏与交互证据：`tests/p3-hud.browser.spec.ts`（桌面、390×844 手机、844×390 横屏、关卡/暂停/音频/成绩），仍执行原本游戏、移动和高分回归；上线后必须以 Pages 的在线 Chromium/WebGL 验收确认。
