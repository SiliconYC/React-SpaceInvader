# P4/B3 · 手工轮廓三维矿物、远近分层和安全边缘（#78）

- **正式源文件：** `src/render/P4RockGeometry.ts`，五种手工曲面/断面组合、明确宽高和厚度比：扁重玄武岩、细长针状石、偏置楔体、铁色团块、薄层板岩。每类独立轮廓、封口和真实三轴体积；`BufferGeometry` 独立面片带原生顶点色和法线，不依赖任何图片材质。
- **现有架构兼容：** `src/render/AsteroidField.ts` 导出原接口；单种只生成一个可编辑源网格和一个实例化 GPU 批次。五类、桌面共 10 枚；紧凑横屏 5 枚、手机竖屏 0 枚；不动主逻辑。
- **边缘特写：** `src/render/ForegroundRocks.ts` 复用同一已入 Git 真网格；四块减少到左右各一块，真正的远近色彩和 3D 阴影，精细而不过载。严格通过 `CombatSceneLayers.isSafeEdgeDecoration` 投影安全检查；不覆盖玩家、敌机、弹药、HUD 或手机触控。
- **自然运动：** 各实例独立速率/相位三维缓转，独立 X/Y 缓漂；冻结和重置确定性；无需动画视频或预渲染贴片。
- **来源授权：** 完全项目内原创参数化数据，原创建模源码即永久可编辑源文件，不使用外部模型/图库。
- **真实 WebGL：** `tests/p4-b3.browser.spec.ts` 记录四种视口、临战运动帧、GPU draw calls/resources JSON；真实 Chromium 截图保留在同一 PR 最新检查工件。`p3-c3-*` 与 `p3-c4-*` 旧截图由 P3 原工作流保存，可用于新旧同视口人工比较。CI 的软件渲染不冒充实体手机 GPU。
- **美术批准：** B 组用户允许先行，但 #69 依旧未人工通过。模型具有真实几何与画面改进可测量，是否已经达到商业级依旧必须由用户判定。
